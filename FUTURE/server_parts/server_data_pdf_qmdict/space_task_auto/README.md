# Space Task Auto Parts

These files are loaded by `FUTURE/server_parts/server_data_pdf_qmdict/03_space_task_auto.py` into the shared Future server runtime namespace.

1. `01_settings.py`: Space Task limits, preferred folder normalization, saved settings.
2. `02_folder_scan.py`: candidate folder order, lesson file scanning, source task rows.
3. `03_payload.py`: final Space Task payload for `/lesson-tasks`.
