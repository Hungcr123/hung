# Future Translation Gate

Files:

- `future.html`: hologram Vietnamese-to-English popup.
- `future_snippet.html`: iframe snippet for embedding.
- `future_lesson_builder_gui.py`: PyQt5 GUI tao file `.txt` ma hoa `FTG1` cho nhieu translation node.

Open directly:

```text
C:\programe\write_html\future.html
```

Embed:

```html
<iframe
  src="future.html?vi=T%C3%B4i%20mu%E1%BB%91n%20m%E1%BB%99t%20ly%20n%C6%B0%E1%BB%9Bc.&en=I%20would%20like%20a%20glass%20of%20water.&ipa=%2Fa%C9%AA%20w%CA%8Ad%20la%C9%AAk%20%C9%99%20%C9%A1l%C3%A6s%20%C9%99v%20%CB%88w%C9%94%CB%90t%C9%99r%2F"
  style="width:100%;height:720px;border:0;border-radius:18px;overflow:hidden;"
></iframe>
```

URL parameters:

- `vi`: Vietnamese question.
- `en`: correct English answer.
- `ipa`: English IPA shown after the answer is correct.
- `accept`: optional extra accepted English answers, separated by `|`.
- `voice`: optional English voice hint, for example `Aria`, `Jenny`, `Guy`, `sot:en-US`, or `Sound of Text`.

Notes:

- The IPA popup also opens after 3 wrong attempts.
- On mobile, the IPA popup stacks below the translation node to avoid overlap.
- The first popup asks the learner to select a local `.txt` lesson file generated by `future_lesson_builder_gui.py`.
- The `Play future` button reads the English sentence with Browser Voice, Edge TTS, or Sound of Text and highlights both the word and its IPA token while it is being read.
- Browser Voice uses real word-boundary events when the browser provides them; Edge and embedded audio fit the highlight timeline to the real audio duration.
- Sound of Text also tries to analyze the returned audio waveform and nudges word boundaries toward quiet gaps, then falls back to the weighted timeline if CORS blocks the audio blob.
- Lesson files generated by the builder include both US and UK IPA, so switching between US/UK voices updates the sentence IPA and token IPA together.
- The voice selector lists English browser voices, English Edge TTS voices, and English Sound of Text choices, and understands communication voice hints such as `female-uk`, `female-us`, `male-us`, and `edge:*`.
- Future Builder can add multiple embedded voices into the generated `FTG1` text file; `future.html` loads those voices from the selected TXT and marks them with a hologram-tinted voice selector state.
- Embedded voice audio is stored per node with its own generated highlight timeline, so learners can select the TXT and play the packaged voices without calling the voice API during the lesson.
- VibeVoice voices appear only when the VibeVoice runtime repo exists at `C:\programe\third_party\VibeVoice-main` and `.pt` voice presets exist under `demo\voices\streaming_model`; otherwise the builder shows a disabled diagnostic entry.
- The fullscreen button first uses the browser fullscreen API; if an embed blocks it, the page opens its current lesson state in an `about:blank` tab.
- Sound of Text uses the same request flow as the main app: create sound, poll status, then play the returned audio URL. Because this is a no-server embed, some browsers may block the direct API call with CORS; Browser Voice remains available.

Create a lesson code file with the PyQt5 builder:

```text
python C:\programe\write_html\future_lesson_builder_gui.py
```

Enter one English sentence per line. `Generate TXT` will translate, build IPA/token analysis/timings, and write a light `FTG1` text file without embedded audio.
