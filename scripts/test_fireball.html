Fireball bubble test (manual)

This page exposes window.__pdfAiTest with hooks into the runtime functions.

Steps:

  1. Open Space_PDF as admin and select a region.
  2. Click Set AI notice, enter text One|Two|Three and Save.
  3. Click the small fireball icon on the page region.
  4. Watch the bubble: type "One", wait ~3s, type "Two", etc. Counter shows 1/3, 2/3, 3/3.
  5. Click the bubble to advance manually.
